# ParsNevis | Blender Persian Text Fixer Addon

**ParsNevis** is a lightweight, clean, and practical add-on for **Blender** that solves the issue of reversed and disconnected Persian and Arabic characters when creating 3D text objects.

---

## 🌟 Features

* **Automatic Persian Text Correction:** Full support for Persian characters («گ چ پ ژ») and correct character joinings.
* **Simple User Interface:** Dedicated tab in the N-Panel for quick, one-click text formatting.
* **No External Tools Needed:** Say goodbye to third-party software and endless copy-pasting.
* **100% Free and Open Source.**

---

## 📥 Installation Guide

1. Download the `.zip` file from the **Free Download Addon** folder in the repository.
2. Open Blender and navigate to:
   `Edit > Preferences > Add-ons`
3. Click on the **Install** button (or **Extensions** in Blender 4.2+) and select the downloaded `.zip` file.
4. Enable the **ParsNevis** add-on check box.

---

## 🚀 How to Use

1. Add a **Text** object to your scene and type your Persian text.
2. Exit Edit Mode (`Tab`).
3. Press **N** on your keyboard to open the side panel and select the **ParsNevis** tab.
4. Click the **Format Correction** button.

> **Note:** To render characters properly, make sure to load a standard Persian font (such as Vazirmatn or IRANSans) in Blender's font settings (`Data > Font`).

---

## 🛠️ Tech Stack & Dependencies

This add-on is developed using Python and relies on:
* `arabic_reshaper`
* `python-bidi`
